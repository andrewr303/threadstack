Import / Export now offers **Import from online accounts → All history**, selected by default for Claude and ChatGPT. All-history requests have no recent-date or 300/500-chat cap. ChatGPT reads normal and archived lists; Claude all-history requests omit the starred filter. Listing emits progress and rejects repeated pages. Reads are paced, cancellable and skip complete unchanged records within the configured account/workspace. A restart rescans the lists and skips stored copies; it does not persist a pagination cursor. The current site session determines which account/workspace is accessible. Deleted/unavailable chats and other accounts are outside this import.
