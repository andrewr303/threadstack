**Deploy guard answers**
- **Live folder without `TK_LIVE_DIR`:** I found no path. `check` hard-sets `TK_OUT_DIR=/tmp/tk-build` and deletes `TK_LIVE_DIR` (`threadkeeper-check.mjs:38-42`). The only other writer is a bare `npm run build` in `extension/`, which targets `extension/.output/`, not the live folder.
- **Key leak:** `deploymentEnv` forces `TK_STABLE_ID='0'`, and `decideManifestKey` returns `key: null` at `build-extension.mjs:110`. I found no leak path.
- **Path tricks:** relative paths are rejected, since `path.isAbsolute` is checked on the raw value. Trailing slashes normalize via `path.resolve`. Symlinks are not resolved (finding 5).
