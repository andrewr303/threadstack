## 2. FR scenario gaps

- **REQ-9 FR-2:** no test for the positive, other-task, no-task or founder-link-unlinked-by-agent scenarios. The activity entry naming the agent is untested.
- **REQ-9 FR-1:** no test for `not_found`, the duplicate, the 50-link limit, or linking across companies.
- **REQ-9 FR-3/FR-5:** `tests/ui.spec.ts` only renders the Browse, Threads and Session board pages. Nothing renders the task tab or the widget (offline row, deleted row, 10 rows plus `View all (25)`).
- **REQ-9 FR-4:** no test for "Paperclip is not running." or for the 10 s removal.
- **REQ-10 FR-2:** no test for two tasks, for a session with no linked task, or for the exact 300-character title with line breaks.
- **REQ-10 FR-3:** no test for no assignee, `waiting_permission`, or a refused wake-up being audited.
- **REQ-10 FR-4:** no test of the 9-change hourly limit or of the 6-per-hour wake cap (the NFR calls for simulated time).
- **REQ-10 FR-5:** the positive case ("Last seen 1 hour ago") has no implementation. The edge case (reloaded and showing Finished, so one event) is contradicted by the ledger design (F2).
- **REQ-10 FR-6:** no test with the setting off.
- **Comment format:** the contract says the comment "ends" with `is now: Failed.` or the suffix. The code appends `<!-- browser-session-event:… -->` as the last line (`state-changes.ts:38`). That is hidden when rendered, but a strict end-of-text check fails.

Items I checked that are fine:
- **Company scoping:** every store query is company-keyed. The data route overrides `companyId` from the verified scope (`worker-rpc-host.ts:2078-2082`).
- **Link provenance:** agent links never grant acting scope (`service.ts:120`, `tools.ts:186`; test at `service.spec.ts:103`).
- **Wake governance:** the host checks done/cancelled status, blockers and budget (`plugin-host-services.ts:2437-2451`), and the plugin audits refusals.
- **Mentions:** Paperclip mentions are link-based (`extractAgentMentionIds`), and `[` and `]` are escaped in the title, so a session title cannot create a mention.

## 4. Top 3 improvements

1. Fix the settle and event pipeline (F1, F2, F4), then add a plugin-plus-ledger integration test with simulated time.
2. Make staleness and copy contract-true, with relative "Last seen" and the widget and setting wording (F3, F6, F7).
3. Add the missing tests for `session_link`/`session_unlink`, the comment formatting and limits, and the task tab and widget UI, and fix the 120-character title cut (F5).
